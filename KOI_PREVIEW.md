### Como escolher a sua favorita:
No seu arquivo `README.md`, basta alterar o caminho da tag `<img>` para o estilo que mais gostar. Por exemplo:
```html
<img src="koi/black/koi.gif" width="256" alt="Samuel's Git Koi" />
```
ou
```html
<img src="koi/asagi/koi.gif" width="256" alt="Samuel's Git Koi" />
```
